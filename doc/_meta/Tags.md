# 🏷️ Tag Taxonomy

Tags used across the Musya Agent knowledge vault. Apply via YAML frontmatter `tags: [...]`.

## Top-level categories

| Tag | Meaning | Used in |
|---|---|---|
| `#architecture` | System-level structural design | `01 - Architecture/` |
| `#agent` | Single-agent specification | `02 - Agents/` |
| `#subsystem` | Cross-cutting subsystem (ThaiJO, RAG, etc.) | `03 - Subsystems/` |
| `#testing` | Test UIs, test plans, QA | `04 - Testing & QA/` |
| `#style-guide` | Writing/output conventions | `05 - Style Guides/` |
| `#status` | Project status & active plans | `06 - Status & Plans/` |
| `#overview` | Onboarding / cross-cutting reference | `07 - Project Overview/` |
| `#moc` | Map of Content / index page | Home, folder MOCs |

## Lifecycle tags

| Tag | Meaning |
|---|---|
| `#status/active` | Live, current, in production |
| `#status/done` | Completed work, retained for reference |
| `#status/proposal` | Design proposal, not yet implemented |
| `#status/archived` | Historical, not actively maintained |
| `#status/wip` | Work in progress |
