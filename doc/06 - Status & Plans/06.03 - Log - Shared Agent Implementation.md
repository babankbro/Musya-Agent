## Overview

Shared Foundation คือ 4 agents แรกที่ทุก pipeline ใช้ร่วมกัน:

| # | Agent | File | Mode |
|---|-------|------|------|
| 1 | Request Interpreter | `request_interpreter.py` | full + short |
| 2 | Data Retrieval Specialist | `retrieval.py` | full + short (minimal) |
| 3 | SQL Specialist | `sql_specialist.py` | full only |
| 4 | Citation & Evidence Agent | `citation_evidence.py` | full only |

Factory entry points ใน `shared_foundation.py`:
```python
build_foundation_agents(llm, include_nlm, include_thaijo, province, notebook_id, mode)
build_foundation_tasks(agents, user_message, province, year, notebook_id, topics, include_nlm, mode)
```

---

## Architecture Decisions

- **Factory pattern**: downstream orchestrators ไม่สร้าง agents โดยตรง — ผ่าน factory เท่านั้น
- **mode flag แทน subclass**: `mode='short'` ตัด SQL + Citation แทนที่จะสร้าง hierarchy ใหม่ — simpler แต่ role/goal text ของ retriever ซ้ำกัน 2 ที่
- **NLM tool injection**: เพิ่ม tools หลัง `Agent()` init ด้วย `agent.tools = list(...) + [nlm_ask, ...]` — brittle ถ้า CrewAI validate tools ตอน init
- **Citation cross-reference**: `parse_evidence_context()` ใน `citation_evidence.py` overwrite `bibliography_text` ด้วยค่าจาก DB เพื่อป้องกัน hallucination — เป็น correctness guard ไม่ใช่ workaround
