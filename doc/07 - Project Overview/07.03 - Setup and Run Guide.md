# 07.03 - Setup and Run Guide

This document explains how to set up and run the Musya Agent project and its related components.

## Project Overview

This project has two main components that run together:

```text
ChatV1 (Next.js :3000)  ←→  Agent (FastAPI :8000)
         ↓
   PostgreSQL + MinIO (Docker)
```

## Step 1 — Start Infrastructure (Docker)

From the `ChatV1/` directory, start the infrastructure services. This starts PostgreSQL (with pgvector), MinIO, and any other shared services.

```bash
cd d:\work\musya\ChatV1
docker-compose up -d
```

## Step 2 — Start Agent Backend (FastAPI)

Open a terminal, navigate to the `Agent/` directory, activate your environment, and start the server.

```bash
cd d:\work\musya\Agent
```

**Option A: use the bat script**
```bash
run_server.bat
```

**Option B: manual (with .venv)**
```bash
.venv\Scripts\activate
python -m uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

**Option C: conda env (musya-agent)**
```bash
conda activate musya-agent
python -m uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

*Verify it's up by visiting:* http://localhost:8000/api/health

## Step 3 — Start ChatV1 Frontend (Next.js)

Open a second terminal, navigate to the `ChatV1/` directory, and start the frontend.

```bash
cd d:\work\musya\ChatV1
npm install        # first time only
npm run dev
```

*Frontend runs at:* http://localhost:3000

## Prerequisites / First-Time Setup

1. **Agent `.env` file** — Copy `Agent/.env.example` to `Agent/.env` and set your `GEMINI_API_KEY` (and `GOOGLE_API_KEY`).
2. **ChatV1 `.env.local`** — Copy `ChatV1/.env.local.example` to `ChatV1/.env.local` and configure DB/API URLs.
3. **DB Migrations** — Run the 21 SQL migration files in `Agent/database` in order (`001` → `021`) manually against the Dockerized PostgreSQL instance using `psql` (e.g., `psql -U postgres -d chat-aio -f database/...`). You can also import the CSV data.
